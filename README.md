This project is a front-end interface for an email client, designed to facilitate sending and receiving emails via API calls. Built with Django and SQLite, the application provides a streamlined solution for managing emails through a user-friendly interface.
Features

    User Authentication: Secure sign-in and user management functionality.
    Send Emails: Compose and send emails to any valid email address.
    Receive Emails: View and manage incoming messages in a clean, intuitive interface.
    Email Management: Organize emails by folders, including inbox, sent, drafts, and more.
    API Integration: Efficient handling of email communications through API calls for sending and retrieving messages.

Technologies Used

    Django: A high-level Python web framework that ensures rapid development with clean, pragmatic design.
    SQLite: A lightweight, self-contained database engine used for storing user data and email information.
    HTML/CSS/JavaScript: Core front-end technologies for a responsive user interface.
    REST API: A simple and effective approach to handle email operations, including sending and retrieving messages.
